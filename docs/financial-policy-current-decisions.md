# QNCH financial policy — current recorded decisions

These choices are ready to save to the QNCH organisation once the migrations are applied. They remain reviewable and date-effective in the application.

| Topic | Recorded decision |
|---|---|
| VAT | Management revenue, margin and P&L are VAT-exclusive. |
| Customer shipping revenue | Use the actual shipping amount from Shopify; keep it separately identifiable within revenue. |
| Outbound shipping cost | Start with a configurable £2.85 per order CM3 assumption; replace/augment it with actual mapped carrier/Xero costs once reconciliation is configured. |
| Refund timing | Recognise refunds on the processed-refund date, retaining the original-order link. |
| CM2 | Paid Meta/TikTok media and approved acquisition spend. |
| CM3 | Fulfilment, carrier shipping, variable Shopify/apps and other approved variable operating costs. |
| New customer | First paid, non-test Shopify order for a resolved customer. |
| CAC | Report actual calculated CM3/first-order break-even CAC and use £35 as the initial configurable maximum-CAC target. |
| Cash | Use the one connected Xero bank account. |
| Inventory | Display 7-day and 30-day run rates; evaluate the primary stock alert using 7-day demand. |

## Still awaiting a choice

1. **COGS method:** choose either date-effective standard landed cost per SKU (recommended for V1), or actual purchase/batch cost. The standard method records a cost such as £X per SKU, plus allocated packaging/inbound freight, and applies it to sales until a new dated cost is approved. Actual/batch cost gives more precision, but needs purchase-order/batch receipt discipline and a stock-costing allocation method.
2. **Agency/creative/affiliate treatment:** direct media spend is already CM2. Choose whether each of the following is a variable acquisition cost in CM2, or a fixed operating expense below CM3: media agency fee, creative production/freelancers, affiliate commission, influencer fee, and retention/CRM spend. The usual V1 starting point is affiliate commission in CM2; retainer agency and creative production fixed; and any percentage-of-spend agency fee in CM2.
